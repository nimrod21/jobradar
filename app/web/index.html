Welcome to JobRadar

register → paste → done

Three short steps. You create the free accounts; the app does all the wiring itself.

1 · Database

Create a free project at supabase.com → New Project (any name; save the database password) → top bar Connect → Session pooler tab → copy the string and put your password into it.

2 · Background Worker

Fork github.com/nimrod21/jobradar (Fork button, top right), then create a token: github.com → Settings → Developer settings → Fine-grained tokens → Generate — select only your fork, give it Secrets: Read and write and Actions: Read and write. The token is used once for wiring and never stored.

3 · AI Fit Scoring optional — everything else works without it
